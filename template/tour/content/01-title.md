# Byeslide

Presentations written as HTML. One file per slide, a theme in CSS, and Reveal.js to present it.

## Speaker notes

This deck is the tour template, the default starter that byeslide init creates. Each slide presents one part of Byeslide and shows one technique; the file it was built from is printed at the bottom left. Watch the name as it prints: two ink plates line up, the same way the build lines up content, theme and runtime.
