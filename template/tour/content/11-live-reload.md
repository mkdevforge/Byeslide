# Save the file, the preview reloads

Recorded from `byeslide preview`. A script edits a slide file, and the browser rebuilds and reloads on its own.

Video: `assets/live-reload.webm`, a 15-second screen recording. First the title slide's sentence changes, then one ink in `theme.css`.

## Speaker notes

This clip is a real recording of the preview server: the edits are writes to a slide file, and the reload is the preview's own file watcher. When an agent edits, you watch the deck change in the browser. Technique: a local video in assets/ with autoplay, muted and loop; Reveal starts and pauses it with the slide.
